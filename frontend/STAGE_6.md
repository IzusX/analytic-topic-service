# Этап 6 — поиск и первая страница выдачи

Статус: реализован и технически проверен. Финальная визуальная приёмка и браузерный рендер остаются открытыми. До начала работ коммит каркаса `b610220` отправлен и проверен в `origin/main`.

## Реализация

- Необязательная тема, поисковый список предпочтительного языка, строковые числовые границы подписчиков, период и объединение точных диапазонов длительности. Allowlist языков проверяется на паритет с backend.
- Pinia хранит draft, текущий успешный response/applied и отдельный pending snapshot. Изменение формы и сброс не отправляют запрос; сброс сохраняет query и выдачу.
- Поиск запускается кнопкой или Enter только в query. IME/composition/legacy229 и implicit form submit не запускают поиск. Валидация до API, ошибки рядом с полем, фокус первого ошибочного поля.
- Одна явная операция получает первую страницу до 50 кандидатов. Дубли во время busy блокируются, AbortController и request-id защищают от устаревших ответов/finally. При уходе на канал запрос отменяется.
- Предыдущие карточки и applied-подписи сохраняются при загрузке и ошибке. Обновление использует applied и пересчитывает относительную нижнюю границу, не меняя draft. Ручной повтор использует снимок неудавшейся операции, включая quota/config errors; автоматических повторов нет.
- Карточки: реальные превью 16:9 с fallback, длительность, название/канал, даты UTC, просмотры/подписчики, независимая голубая шкала отношения. Полные названия и точные числа доступны через details, не только hover. null/0/подтверждённое скрытие не смешиваются.
- Оригинал видео открывается на YouTube в новой вкладке с безопасным rel. Канал/действие анализа ведут на внутренний маршрут с исходным videoId, без prefetch. Сам экран анализа ещё заготовка.
- Initial/loading/dirty/empty/error/retry состояния. Пустая страница с next token не объявляется концом всех совпадений. Пагинация и сортировка пока отсутствуют.

## Финальные проверки

- **299 frontend-тестов прошли**: модель 59, store 43, реальные Vue/jsdom взаимодействия страницы 30, карточки 7, форматирование 23, варианты/подписи 6, исходные API/theme/App тесты.
- `npm run typecheck`, `npm run build` и синтаксис live-скрипта прошли.
- **202 backend-теста прошли**, одно прежнее неблокирующее deprecation-предупреждение Starlette.
- Read-only технический обзор выявил две P2 ошибки фокуса: language wrapper вместо input и отсутствие фокуса после retry422. Исправлены `focusInput()` и общей post-action функцией; два real-component регрессионных теста прошли.
- Полный прогон также выявил гонку тестового ожидания первого lazy-import маршрута. Assertion теперь ждёт фактического завершения навигации (`vi.waitFor`), а не одного microtask flush. Production-навигация ради теста не менялась.

Повтор этого скрипта расходует квоту и требует явного opt-in:


## Открытые границы

Chrome ранее был заблокирован sandbox/Crashpad; отказ не обходился и повторно браузер не запускался. Нет актуальных screenshot/viewport approvals. jsdom не проверяет popup hit-testing NSelect, физическое IME, touch, layout/переполнение и screen-reader поведение. Старый browser-стенд этапа 5 не покрывает новую форму и карточки; для реальной приёмки его необходимо расширить.

Один текущий response в памяти Pinia сохраняется при SPA-переходах, но это не stage8 cache: нет sessionStorage, нескольких выдач/LRU, reload/scroll restoration или cache-hit идентичного запроса. До этапа 8 явный повторный поиск может снова расходовать квоту.

Этапы 7–12 не выполнялись: нет пагинации/сортировки, сессионного кеша, аналитического экрана/графика или финальной визуальной полировки. Следующий этап 7 начинается только по отдельному разрешению.
