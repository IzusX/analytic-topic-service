# Этап 7: продолжение и сортировка

Сохраняется существующая графитово-фиолетовая система. Без редизайна: над результатами добавлен подписанный native select «Сортировка загруженных видео», под сеткой — явная кнопка «Показать ещё» и статус продолжения.

Один клик обрабатывает одну страницу до 50 кандидатов по applied и замороженной UTC-границе. Ни draft, ни локальный sort не меняют условия API. Уникальные видео накапливаются в исходном порядке; первое целое наблюдение ID сохраняется. Сортировка работает на копии: YouTube, просмотры, дата, отношение; пропуски в конце.

Старые карточки остаются при догрузке/ошибке. Пустая/дублирующая страница не вызывает автоматической следующей. Повтор циклического token останавливается с объяснением. Время относится к последней полученной странице, не к единому моменту всех карточек.

Пользователь сообщил, что этап 6 работает и корректно отображается. Это ручная обратная связь о предыдущем экране, не автоматический audit новых состояний. Проверка новых взаимодействий — тесты Vue/jsdom; реальный browser viewport остаётся отдельной работой. Этап 8 и аналитика не входят в объём.
